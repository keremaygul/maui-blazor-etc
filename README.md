## 🛠 Tech Stack

- **.NET 10** / C#
- **MAUI** (Multi-platform App UI)
- **Blazor** (Hybrid & WebAssembly)
- **AL** (Business Central Extensions)
- **Protobuf / gRPC**
- **Monaco Editor**

## 🎯 Goal

Learn the key technologies used in Microsoft Dynamics 365 Business Central ecosystem development, including mobile/web app development with Blazor MAUI, ERP customization with AL, and supporting tools.

## 📋 Prerequisites

- .NET 10 SDK
- Visual Studio 2022+ or VS Code
- Node.js 18+
- Git
